# Security

This is an unauthenticated localhost teaching service, not a multi-user document system. Keep Uvicorn bound to `127.0.0.1`; do not expose it through a public proxy without authentication, access control and a document retention plan. `RAG_DOCUMENT_ROOT` limits readable files, but indexed text is available to any local process that can query this API. Prompt injection and malicious PDF handling are not production-reviewed. Report security concerns privately to the repository owner through GitHub's security advisory feature where available; avoid uploading sensitive sample documents to public issues.

Generative mode sends a bounded question and up to three retrieved excerpts only to an explicitly configured literal-loopback HTTP endpoint. It uses no API key, HTTP proxy or redirects. This cannot certify that the local server itself does not forward or log content. Sources are untrusted JSON evidence under a fixed system instruction; no tools are executed. Citation ID checks reject nonexistent references but cannot prove factual support or prompt-injection resistance. Review cited text. Model/runtime authenticity, licence and hash verification belong to a separate real-model check. Model errors do not silently become extractive answers.
