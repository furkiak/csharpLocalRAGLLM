# Northstar sample handbook

This is invented, public test data for the local retrieval demo. It is not a real company policy.

Return period: Products can be returned within 30 days of delivery.
Support window: The demo support desk is open Tuesday and Thursday from 09:00 to 17:00.
Backup schedule: The sample database is backed up at 02:00 UTC every night.
Retention period: Deleted demo accounts are retained for seven days before purge.
Export format: The sample export is a UTF-8 CSV file.
Invoice currency: Example invoices use EUR.
Trial duration: The fictional trial lasts 14 days.
Project owner: The sample handbook is maintained by the Documentation Team.
Release channel: The demo offers a preview channel only.
Issue response: A sample issue receives a first response within three business days.
