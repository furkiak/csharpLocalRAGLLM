# Contributing

Keep examples synthetic. Run `python -m pytest -q`, `python eval/run.py`, and `dotnet build -c Release` before proposing a change. If retrieval behavior changes, include a source document, a question, the expected source/no-answer result and a case that fails before the fix. Do not commit real customer PDFs, index data, API keys or model weights. Explain model licenses and exact download steps before adding a model dependency.
